# MULTIMODAL 학습 용어 정리

각 용어의 핵심 설명과 예시입니다. 용어 이름을 누르면 자세한 설명을 볼 수 있습니다.

| 용어 | 간단한 설명 | 예시 |
| --- | --- | --- |
| [Embedding (임베딩)](./용어설명/Embedding.md) | 단어, 이미지 등의 데이터를 모델이 활용할 수 있는 숫자 벡터로 표현하는 것 | ‘고양이’ 토큰을 `[0.2, -0.5, 0.8, ...]` 같은 벡터로 표현. 숫자는 설명용 예시 |
| [Hidden State (은닉 상태)](./용어설명/Hidden_State.md) | RNN이 현재 입력과 이전 상태를 바탕으로 계산하여 다음 시점으로 전달하는 기억 벡터 | 최근 20거래일을 순서대로 처리한 마지막 기억을 이용해 다음 거래일 종가 예측 |
| [Transformer (트랜스포머)](./용어설명/Transformer.md) | Attention으로 토큰 사이 관계를 계산하고 문맥이 반영된 표현을 만드는 신경망 구조 | ‘커피 한잔 어때’의 세 토큰이 서로를 참고하여 각자의 벡터를 갱신 |
| [Accuracy (다중 라벨 정확도)](./용어설명/Accuracy.md) | 한 문장의 모든 라벨을 정확히 맞힌 비율 | 10문장 중 6문장 완전 일치 → 0.6 |
| [F1 Score](./용어설명/F1_Score.md) | 정밀도와 재현율의 조화평균 | Precision 0.75, Recall 0.6 → F1 약 0.667 |
| [Macro F1](./용어설명/F1_Macro.md) | 라벨별 F1을 같은 비중으로 평균 | F1 0.9, 0.6, 0.3 → 0.6 |
| [Micro F1](./용어설명/F1_Micro.md) | 전체 TP·FP·FN을 합산한 뒤 계산한 F1 | TP 80, FP 10, FN 30 → 0.8 |
| [Weighted F1](./용어설명/F1_Weighted.md) | 라벨별 실제 양성 수로 가중평균한 F1 | F1 0.9/0.3, 양성 수 90/10 → 0.84 |
| [ROC-AUC](./용어설명/ROC_AUC.md) | 여러 임계값에 걸친 양성·음성 점수 구분 성능 | 양성 0.9, 음성 0.8 → AUC 1.0 |
| [ViT (Vision Transformer)](./용어설명/ViT.md) | 이미지를 패치 토큰으로 바꾸어 Transformer로 처리하는 이미지 인식 모델 | 224×224 이미지를 16×16 패치 196개로 나누어 분류 |
| [FFN (Feed-Forward Network)](./용어설명/FFN.md) | 순환 연결 없이 입력에서 출력 방향으로 정보를 처리하는 신경망 | Transformer에서 각 토큰을 8 → 32 → 8차원으로 가공 |
| [MLP (Multi-Layer Perceptron)](./용어설명/MLP.md) | 여러 완전연결층과 활성화 함수로 구성한 FFN의 한 종류 | ViT에서 Linear → GELU → Linear로 각 토큰 벡터 가공 |
| [LayerNorm (Layer Normalization)](./용어설명/LayerNorm.md) | 각 토큰의 특징 차원을 기준으로 평균과 분산을 계산해 값을 정규화하는 연산 | `(2, 5, 32)` 입력에 `LayerNorm(32)`를 적용하면 각 토큰의 32개 값을 정규화하며 모양은 유지|
| [Backbone (백본)](./용어설명/Backbone.md) | 입력에서 작업에 필요한 특징을 추출하는 모델의 중심 부분 | ViT가 이미지 특징을 추출하고, 분류 head 4개가 각 자리의 숫자를 예측 |
| [AMP (Automatic Mixed Precision)](./용어설명/AMP.md) | 연산에 따라 FP16·BF16과 FP32를 자동으로 섞어 사용하는 기법 | CUDA에서 autocast로 정밀도를 선택하고 FP16 학습에서는 GradScaler로 작은 기울기 소실 완화 |
| [Zero-shot (제로샷)](./용어설명/Zero_shot.md) | 새로운 작업의 정답 예제를 제공하지 않고 사전학습된 능력으로 수행하는 방식 | CLIP에서 이미지와 고양이·강아지 설명 문장의 유사도를 비교해 분류 |
| [L2 정규화](./용어설명/L2_Normalization.md) | 0이 아닌 벡터를 자신의 L2 길이로 나누어 길이를 1로 만드는 연산 | `[3, 4]`를 길이 5로 나누면 `[0.6, 0.8]` |
| [Cosine 유사도 (코사인 유사도)](./용어설명/Cosine_Similarity.md) | 두 벡터의 방향이 얼마나 비슷한지 나타내는 값 | 같은 방향은 1, 수직은 0, 정반대 방향은 -1 |
| [NMS (Non-Maximum Suppression)](./용어설명/NMS.md) | 탐지 점수가 높은 bounding box를 남기고 많이 겹치는 낮은 점수의 후보를 제거하는 후처리 | 같은 컵의 후보 A·B 중 A의 점수가 높고 IoU가 기준을 넘으면 B 제거 |
| [IoU (Intersection over Union)](./용어설명/IoU.md) | 두 영역의 교집합 면적을 합집합 면적으로 나누어 겹치는 정도를 나타내는 값 | 각 bounding box 면적이 100이고 겹친 면적이 81이면 IoU는 81/119 ≈ 0.681 |

상세 문서는 `용어설명` 폴더에 용어별로 보관합니다.
