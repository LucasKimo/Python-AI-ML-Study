# L2 정규화 (L2 Normalization)

[용어 목록으로 돌아가기](../용어설명.md)

## 정의

L2 정규화는 0이 아닌 벡터를 자신의 길이(L2 norm)로 나누어 **방향은 유지하고 길이는 1로 만드는 연산**입니다. 벡터를 화살표로 생각하면, 화살표가 가리키는 방향은 그대로 두고 길이만 맞추는 것입니다.

```text
벡터 x의 L2 길이 = sqrt(x₁² + x₂² + ... + xD²)
정규화된 벡터 = x / 벡터의 L2 길이
```

## 필요한 이유

임베딩을 비교할 때 벡터 크기의 영향을 없애고 방향을 비교하려고 사용합니다. 특히 CLIP에서는 이미지와 텍스트 벡터를 각각 정규화하면, 두 벡터의 내적만으로 [Cosine 유사도](./Cosine_Similarity.md)를 계산할 수 있습니다.

정규화 자체가 벡터에 의미를 부여하지는 않습니다. 이미지와 문장의 방향이 의미 있게 대응하는 것은 CLIP이 그렇게 사전학습되었기 때문입니다.

## 구체적인 예시

벡터가 `[3, 4]`라면 길이는 다음과 같습니다.

```text
sqrt(3² + 4²) = sqrt(25) = 5
[3, 4] / 5 = [0.6, 0.8]
새 길이 = sqrt(0.6² + 0.8²) = 1
```

`[6, 8]`도 같은 방향이므로 정규화하면 `[0.6, 0.8]`이 됩니다.

## 관련 코드와 주석

```python
import torch
import torch.nn.functional as F

x = torch.tensor([[3.0, 4.0], [6.0, 8.0]])
# shape: (벡터 수 2, 특징 차원 2)

normalized = F.normalize(x, p=2, dim=-1)
# p=2: L2 norm 사용
# dim=-1: 마지막 특징 축을 기준으로 각 벡터를 따로 정규화
# 결과: [[0.6, 0.8], [0.6, 0.8]]
# 입력과 출력의 shape은 동일

image_features = F.normalize(image_features, p=2, dim=-1)
text_features = F.normalize(text_features, p=2, dim=-1)
# 위 두 줄은 CLIP에서 얻은 임베딩이 준비되어 있다고 가정
```

0벡터는 길이가 0이어서 수학적으로 단위 벡터로 정규화할 수 없습니다. `F.normalize`는 작은 값 `eps`를 이용해 0으로 나누는 것을 방지하며, 0벡터는 0벡터로 남습니다. 길이가 eps보다 작은 벡터도 출력 길이가 정확히 1이 되지는 않습니다.

## 혼동하기 쉬운 개념과의 차이

| 개념 | 차이 |
| --- | --- |
| L2 norm | 벡터의 길이를 구한 숫자입니다. L2 정규화는 그 길이로 벡터를 나누는 연산입니다. |
| L2 규제(regularization) | 큰 가중치에 벌점을 주는 학습 방법입니다. 벡터 길이를 1로 만드는 L2 정규화와 다릅니다. |
| LayerNorm | 특징의 평균과 분산으로 정규화하고 학습 가능한 변환을 적용합니다. 출력 벡터 길이를 1로 만드는 연산은 아닙니다. |
| Softmax | 값들을 합이 1인 양수 가중치로 바꿉니다. L2 정규화는 제곱합이 1이 되도록 하며 음수도 유지됩니다. |
