# LayerNorm (Layer Normalization)

[용어 목록으로 돌아가기](../용어설명.md)

## 정의

LayerNorm은 지정한 특징 차원의 값들로 평균과 분산을 구하고, 이를 기준으로 값을 정규화하는 연산입니다. Transformer에서는 보통 **각 토큰의 특징 벡터를 따로 정규화**합니다.

현재 [ViT 실습](../10_ViT.ipynb)에서 입력이 `(B, N + 1, D) = (2, 5, 32)`라면 이미지 2장에 각각 CLS를 포함한 토큰 5개가 있고, 각 토큰은 숫자 32개로 표현됩니다. `nn.LayerNorm(32)`는 **토큰 하나 안의 숫자 32개**를 기준으로 계산합니다. 이미지끼리 또는 토큰끼리 평균을 내지 않습니다.

## 왜 필요한가?

Transformer의 여러 층을 지나면서 특징값의 크기와 분포가 달라질 수 있습니다. LayerNorm은 다음 연산에 들어가는 값의 규모를 조절하여 학습을 안정적으로 진행하는 데 도움을 줍니다.

패치 정보를 모으거나 토큰 사이의 관계를 계산하는 역할은 아닙니다. 토큰 사이의 정보 교환은 Self-Attention이 담당합니다.

## 구체적인 계산 예시

설명을 위해 토큰 하나가 `[1, 2, 3, 4]`라고 가정합니다.

1. 평균은 `2.5`입니다.
2. 평균을 빼면 `[-1.5, -0.5, 0.5, 1.5]`입니다.
3. 분산은 제곱 편차의 평균인 `1.25`입니다.
4. 각 값을 `sqrt(1.25 + eps)`로 나누면 약 `[-1.342, -0.447, 0.447, 1.342]`가 됩니다.

마지막에는 학습 가능한 크기 조절 값 `gamma`와 이동 값 `beta`를 적용합니다.

```text
출력 = gamma * (입력 - 평균) / sqrt(분산 + eps) + beta
```

`eps`는 0으로 나누는 문제를 막는 작은 값입니다. 정규화 직후 값은 평균이 약 0, 분산이 약 1이지만, 학습된 `gamma`와 `beta`까지 적용한 최종 출력이 항상 평균 0, 분산 1인 것은 아닙니다.

## ViT 코드와 shape

```python
import torch
import torch.nn as nn

# 이미지 2장, 이미지마다 CLS + 패치 토큰 5개, 특징 32개
x = torch.randn(2, 5, 32)

# 마지막 차원의 32개 값을 기준으로 토큰마다 따로 정규화
# 기본 설정에서 gamma와 beta는 각각 (32,)이며 모든 토큰이 공유
norm = nn.LayerNorm(32)
y = norm(x)

print(y.shape)  # torch.Size([2, 5, 32])
```

LayerNorm은 토큰을 추가하거나 특징 차원을 줄이지 않으므로 입력과 출력의 모양이 같습니다. `32`는 배치 크기나 토큰 수가 아니라 **정규화할 마지막 차원의 크기**입니다. 일반적으로 `normalized_shape`에 여러 차원을 지정하면 그 마지막 여러 차원을 함께 정규화합니다.

ViT에서 사용하는 Pre-Norm 구조는 보통 다음 흐름입니다.

```python
# norm1, norm2: nn.LayerNorm(D)
# attention은 (B, 토큰 수, D) 텐서를 반환한다고 가정
x = x + attention(norm1(x))
x = x + mlp(norm2(x))
```

Attention과 MLP에 들어가기 전에 정규화하고, 각 연산 결과를 기존 입력에 더합니다. 이 덧셈은 잔차 연결(Residual Connection)입니다.

## 혼동하기 쉬운 개념과의 차이

| 개념 | 역할과 차이 |
| --- | --- |
| BatchNorm | 배치의 여러 샘플을 포함한 축에서 통계를 계산합니다. LayerNorm은 각 샘플 안의 지정한 특징 차원에서 계산하므로 다른 이미지의 값에 의존하지 않습니다. |
| Softmax | 점수들을 합이 1인 가중치로 바꿉니다. LayerNorm의 출력은 음수일 수 있고 합이 1일 필요가 없습니다. |
| 입력 이미지 정규화 | 모델에 넣기 전 픽셀값을 조절하는 전처리입니다. LayerNorm은 모델 내부의 특징 벡터에 적용됩니다. |
| Position Embedding | 토큰의 위치 정보를 더합니다. LayerNorm은 위치 정보를 새로 추가하지 않습니다. |

기본 LayerNorm은 BatchNorm처럼 이동 평균 통계를 따로 쌓지 않으며, 학습과 평가 모두 현재 입력으로 평균과 분산을 계산합니다.
