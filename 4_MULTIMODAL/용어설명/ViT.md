# ViT (Vision Transformer)

[용어 목록으로 돌아가기](../용어설명.md)

## 1. 정의

ViT는 이미지를 작은 패치로 나누고, 각 패치를 토큰 벡터로 바꾸어 Transformer Encoder로 처리하는 이미지 인식 모델입니다. 텍스트 Transformer가 단어·서브워드 토큰 사이 관계를 처리하듯, ViT는 이미지 패치 사이 관계를 처리합니다.

학습 자료: [10_ViT.ipynb](../10_ViT.ipynb). 아래 설명은 기본 ViT 구조에 대한 개념 정리입니다.

## 2. 왜 패치로 나누나요?

Transformer에는 벡터의 시퀀스를 입력합니다. 이미지를 패치 단위로 바꾸면 같은 구조를 활용할 수 있고, 픽셀마다 하나의 토큰을 만드는 것보다 토큰 수도 줄일 수 있습니다. 패치는 물체 단위가 아닌 고정된 격자 조각입니다. 한 패치에 고양이 귀의 일부와 배경이 함께 들어갈 수도 있습니다.

## 3. 작동 과정과 구체적인 예시

RGB 이미지 224×224, 패치 16×16, 임베딩 차원 768인 예시입니다. 이미지 크기가 패치 크기로 나누어떨어진다고 가정합니다.

```text
이미지 (3, 224, 224)
  → 16×16 패치 196개 (14×14)
  → 각 패치의 픽셀을 펼치기: 16×16×3 = 768개 값
  → 학습 가능한 선형 투영: 패치당 768차원 임베딩
  → 학습 가능한 [CLS] 벡터 추가: 총 197개 토큰
  → 위치 임베딩 더하기
  → Transformer Encoder 여러 층
  → 마지막 층의 [CLS] 표현
  → 분류기 → 클래스별 점수(logits)
```

픽셀을 펼친 길이와 임베딩 차원이 여기서는 우연히 768로 같습니다. 임베딩 차원은 설계값이며 둘이 같아야 할 필요는 없습니다. 선형 투영은 값이 같은 크기여도 학습 가능한 변환입니다.

### Patch Embedding

각 패치의 픽셀값을 공통 선형 변환으로 벡터화합니다. 텍스트처럼 정수 토큰 ID로 임베딩 표를 조회하는 과정은 기본 ViT 패치 임베딩에 필요하지 않습니다.

### [CLS] 토큰

원래 이미지에 있는 조각이 아니라 분류용으로 추가한 학습 가능한 벡터입니다. Self-Attention을 거치며 패치 정보를 반영한 표현이 되고, 마지막 표현을 분류기에 전달합니다. 단순한 패치 평균은 아닙니다. 원래 ViT의 대표적인 분류 방식이며 변형 모델은 평균 풀링 등을 쓰기도 합니다.

### 위치 임베딩

패치가 이미지의 어느 위치에 있었는지 알려 주기 위해 더합니다. 기본 ViT는 학습 가능한 위치 임베딩을 사용합니다. 앞서 배운 Sin/Cos 위치 인코딩과 목적은 비슷하지만 값의 생성 방식은 다릅니다.

### Self-Attention과 FFN

Self-Attention은 Q/K/V를 사용해 패치 토큰과 [CLS] 사이 정보를 섞습니다. 예를 들어 고양이의 귀 부분 패치가 멀리 있는 얼굴·몸통 패치와 직접 관계를 계산할 수 있습니다. 이는 설명용 예시이며 Head마다 고정된 신체 부위 역할이 있는 것은 아닙니다.

FFN은 각 토큰을 개별적으로 비선형 가공합니다. Residual과 LayerNorm은 정보 전달과 안정적인 학습을 돕습니다. 원래 ViT 블록은 각 Attention/MLP 앞에 LayerNorm을 두는 Pre-LN 방식입니다. 기존 Transformer 실습의 Post-LN과 배치 순서가 다를 수 있습니다.

## 4. 패치 임베딩을 확인하는 코드

```python
import torch
import torch.nn as nn

images = torch.randn(2, 3, 224, 224)  # 이미지 2장

# 겹치지 않는 16×16 패치를 공통 선형 변환하는 구현
patch_embed = nn.Conv2d(3, 768, kernel_size=16, stride=16)
x = patch_embed(images)       # (2, 768, 14, 14)
x = x.flatten(2).transpose(1, 2)  # (2, 196, 768)

cls_token = nn.Parameter(torch.zeros(1, 1, 768))
position_embed = nn.Parameter(torch.zeros(1, 197, 768))

cls = cls_token.expand(images.size(0), -1, -1)
x = torch.cat([cls, x], dim=1)  # (2, 197, 768)
x = x + position_embed        # 위치 정보 추가

# 다음 단계: Encoder → 마지막 [CLS] 표현 → 분류기
```

shape를 설명하는 예시이며 완성된 학습 모델은 아닙니다. 실제 모델에서는 이 파라미터들을 nn.Module 안에 등록하고 적절히 초기화·학습합니다. Conv2d 사용은 패치별 선형 투영의 구현 방법이며, 이것만으로 깊은 CNN 구조가 되는 것은 아닙니다.

## 5. CNN 및 BERT와의 차이

| 비교 | 기본적인 특징 |
| --- | --- |
| CNN | 작은 지역 영역을 합성곱으로 처리하며 층을 쌓아 넓은 영역의 정보를 결합 |
| 기본 ViT | 첫 Self-Attention 층부터 전체 패치 토큰 사이 관계를 계산할 수 있음 |
| BERT | 텍스트 토큰을 입력하며 임베딩 표를 조회 |
| ViT | 이미지 패치의 픽셀을 투영한 벡터를 입력 |

전역 관계를 계산할 수 있다는 것은 처음부터 물체를 이해한다는 뜻이 아닙니다. 의미 있는 관계는 학습해야 합니다. ViT가 언제나 CNN보다 좋은 것도 아닙니다. 성능은 데이터, 사전학습, 증강, 모델 크기와 학습 방법 등에 달려 있습니다. 분류 이후 검출·분할 등으로 활용하는 과제가 다운스트림 작업입니다.

## 6. 패치가 작아지면 왜 비용이 커지나요?

패치 수는 N=(H/P)×(W/P)입니다. 패치 한 변 P를 절반으로 줄이면 패치 수는 4배가 됩니다. 표준 전역 Self-Attention에서 관계 점수 행렬은 대략 N×N이므로 이 부분의 크기는 약 16배가 됩니다([CLS] 제외 근사).

| 이미지 | 패치 | 패치 수 |
| --- | --- | --- |
| 224×224 | 16×16 | 196 |
| 224×224 | 8×8 | 784 |

토큰 수에 대한 O(N²)은 Attention 관계 계산의 특성입니다. 모델 전체의 모든 연산이 오직 N²에만 비례한다는 뜻은 아닙니다.
