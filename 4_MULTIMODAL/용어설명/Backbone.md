# Backbone (백본)

[용어 목록으로 돌아가기](../용어설명.md)

## 정의

Backbone은 입력 데이터에서 작업에 필요한 특징을 추출하는 모델의 중심 부분입니다. 특정 계층 하나의 이름이 아니라, 전체 모델에서 맡는 역할을 가리키는 말입니다. CNN이나 ViT 등 다양한 구조가 backbone이 될 수 있습니다.

이미지 분류 모델은 보통 다음처럼 이해할 수 있습니다.

```text
입력 이미지 → Backbone(특징 추출) → Head(최종 예측)
```

Backbone은 선, 모양, 위치 관계 등 예측에 유용한 정보를 숫자 표현으로 만들고, head는 그 표현을 이용해 원하는 정답의 점수를 계산합니다. 특징 벡터의 각 숫자가 사람이 이름 붙일 수 있는 특정 특징 하나에 정확히 대응하는 것은 아닙니다.

## 왜 필요한가?

특징 추출 부분과 최종 예측 부분을 나누면, 이미 학습된 특징 추출기를 새로운 문제에 활용할 수 있습니다. 또한 여러 분류기가 공통 backbone을 공유하여 같은 특징을 서로 다른 예측에 사용할 수 있습니다.

사전학습은 backbone의 필수 조건이 아닙니다. 처음부터 학습하는 모델에도 backbone이 있으며, 사전학습된 backbone도 별도로 고정하지 않으면 학습 과정에서 가중치가 갱신됩니다.

## 현재 ViT 실습의 예시

[ViT 실습](../10_ViT.ipynb)은 이미지 한 장에 있는 네 자리 숫자를 각각 예측합니다.

```text
이미지 "1234"
      ↓
공유 ViT Backbone
      ↓
이미지 특징 벡터
      ├─ Head 1 → 첫째 자리: 1
      ├─ Head 2 → 둘째 자리: 2
      ├─ Head 3 → 셋째 자리: 3
      └─ Head 4 → 넷째 자리: 4
```

ViT에서는 패치 임베딩과 Transformer Encoder 등이 특징 추출을 담당합니다. 이미지 대표 벡터를 얻는 방법은 모델 설정에 따라 CLS 토큰 사용 또는 pooling 등으로 달라질 수 있습니다.

네 head는 동일한 이미지 특징 벡터를 받지만, 각각 별도의 가중치를 학습합니다. Backbone을 네 개 만드는 것도, 이미지를 네 조각으로 나누어 각 head에 전달하는 것도 아닙니다.

## 관련 코드와 shape

다음은 실습 모델의 핵심 흐름입니다. `B`는 이미지 수, `D`는 backbone의 출력 특징 차원입니다.

```python
# 모델 생성 시 준비한 공통 특징 추출기
# self.backbone: 기존 분류기를 제거한 ViT

features = self.backbone(x)
# 입력 x: (B, 3, 224, 224)
# 출력 features: (B, D) — 이미지마다 특징 벡터 하나

outputs = [head(features) for head in self.heads]
# 각 head는 D차원 특징을 숫자 0~9의 점수로 변환
# 출력: (B, 10) Tensor 4개가 들어 있는 리스트
```

예를 들어 이미지가 2장이고 출력 특징 차원이 768인 모델이라면, backbone 출력은 `(2, 768)`, 각 분류 head의 출력은 `(2, 10)`입니다. 768은 설명용 예시이며 실제 차원은 선택한 모델의 `num_features`로 확인합니다.

## 혼동하기 쉬운 개념과의 차이

| 개념 | Backbone과의 관계 또는 차이 |
| --- | --- |
| Classification head | Backbone이 추출한 특징으로 클래스별 점수를 계산하는 마지막 부분입니다. |
| Encoder | 입력을 특징 표현으로 바꾸는 구조입니다. 현재 ViT의 Transformer Encoder는 backbone의 핵심 구성 요소입니다. 두 용어의 범위가 항상 같은 것은 아닙니다. |
| 사전학습 모델 | 과거 데이터로 가중치를 학습한 모델입니다. 그 모델의 특징 추출 부분을 backbone으로 재사용할 수 있습니다. |
| Backbone 고정(freeze) | Backbone의 가중치를 학습 중 갱신하지 않는 설정입니다. Backbone이라는 이름만으로 자동 고정되지는 않습니다. |
| Attention head | Transformer 내부에서 관계를 계산하는 단위입니다. Backbone 뒤에 붙는 분류 head와 다릅니다. |
