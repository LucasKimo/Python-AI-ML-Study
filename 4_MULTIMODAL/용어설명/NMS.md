# NMS (Non-Maximum Suppression, 비최대 억제)

[용어 목록으로 돌아가기](../용어설명.md)

## 정의

NMS는 **탐지 점수가 높은 bounding box를 남기고, 그 bounding box와 많이 겹치는 낮은 점수의 후보 bounding box를 제거하는 후처리 방법**입니다. 같은 물체에 bounding box가 여러 개 그려지는 중복 탐지를 줄일 때 사용합니다.

쉽게 말하면 “같은 컵을 여러 번 찾은 것 같으니, 점수가 높은 bounding box를 대표로 남기자”라는 처리입니다. 이름의 Non-Maximum Suppression은 가장 높은 점수의 후보 외에 겹치는 후보를 억제한다는 의미로 이해하면 됩니다.

## 필요한 이유

객체 탐지 모델은 컵 하나에 대해 위치와 크기가 조금씩 다른 후보 bounding box를 여러 개 만들 수 있습니다. 이를 모두 표시하면 컵 하나에 bounding box가 여러 겹 생깁니다.

```text
사진 → 탐지 모델 → 후보 bounding box와 점수 → NMS → 정리된 bounding box
```

NMS는 이미 나온 후보를 정리하는 단계이며, 물체의 의미나 위치를 새로 학습하는 단계는 아닙니다. 모든 객체 탐지 모델이 반드시 NMS를 사용하는 것은 아닙니다.

## 작동 순서

1. 남은 후보 중 점수가 가장 높은 bounding box를 선택해 결과에 보관합니다.
2. 선택한 bounding box와 다른 후보의 [IoU](./IoU.md)를 계산합니다.
3. IoU가 정한 기준보다 큰 후보를 중복으로 간주해 제거합니다.
4. 남은 후보에서 같은 과정을 반복합니다.

여기서 IoU는 두 bounding box가 겹치는 정도입니다. **bounding box의 위치를 비교하는 값**이며, 모델이 각 후보에 부여한 **탐지 점수와는 다릅니다.**

## 구체적인 예시

사진에 컵 두 개가 있고, 다음 후보가 나왔다고 가정합니다. 좌표와 점수는 설명용 예시입니다.

| 후보 | 나타내는 대상 | 좌표 `(x1, y1, x2, y2)` | 탐지 점수 |
| --- | --- | --- | --- |
| A | 첫 번째 컵 | `(0, 0, 10, 10)` | 0.95 |
| B | 첫 번째 컵의 중복 후보 | `(1, 1, 11, 11)` | 0.88 |
| C | 떨어져 있는 두 번째 컵 | `(20, 20, 30, 30)` | 0.76 |

IoU 기준이 `0.5`라면:

- A의 점수가 가장 높으므로 A를 남깁니다.
- A와 B의 IoU는 약 `0.681`입니다. `0.5`보다 크므로 B를 제거합니다.
- A와 C의 IoU는 `0`입니다. 서로 겹치지 않으므로 C는 남아 다음에 선택됩니다.

**최종 결과는 A와 C입니다.** 점수가 낮다는 이유만으로 모든 bounding box를 제거하는 것이 아니라, 선택한 bounding box와 많이 겹치는 후보를 제거합니다.

## 관련 코드와 주석

아래는 PyTorch와 torchvision이 설치된 환경을 가정한 독립 예시입니다. 노트북에 추가하거나 실행한 코드는 아닙니다.

```python
import torch
from torchvision.ops import nms

# 세 후보는 모두 같은 클래스인 '컵'이라고 가정
# 각 행: [왼쪽 위 x, 왼쪽 위 y, 오른쪽 아래 x, 오른쪽 아래 y]
boxes = torch.tensor([
    [0.0, 0.0, 10.0, 10.0],    # A: 첫 번째 컵
    [1.0, 1.0, 11.0, 11.0],    # B: A와 많이 겹치는 중복 후보
    [20.0, 20.0, 30.0, 30.0],  # C: 두 번째 컵
])  # shape: (후보 수 3, 좌표 수 4)

# 각 후보에 모델이 부여한 점수. 여기서는 설명용 값
scores = torch.tensor([0.95, 0.88, 0.76])  # shape: (3,)

# 높은 점수의 bounding box와 IoU가 0.5를 넘는 다른 후보를 제거
keep = nms(boxes, scores, iou_threshold=0.5)

# keep은 bounding box 자체가 아니라 살아남은 bounding box의 인덱스
# 이 예시의 예상 인덱스: [0, 2] → A와 C
kept_boxes = boxes[keep]
kept_scores = scores[keep]
```

`torchvision.ops.nms`는 클래스 정보를 인자로 받지 않습니다. 클래스별로 중복을 제거하려면 같은 클래스끼리 나누어 적용하거나, 클래스 정보를 받는 별도 함수를 사용해야 합니다.

## 혼동하기 쉬운 개념과의 차이

| 개념 | NMS와의 차이 |
| --- | --- |
| [IoU](./IoU.md) | 두 bounding box의 겹침을 계산한 숫자입니다. NMS는 그 숫자와 탐지 점수로 후보를 선택·제거하는 절차입니다. |
| 탐지 점수 기준 | 예를 들어 점수가 0.3 미만인 후보를 제거합니다. NMS의 IoU 기준은 다른 bounding box와 얼마나 겹치는지 판단합니다. |
| 객체 탐지 모델 | 이미지에서 bounding box와 점수를 예측합니다. NMS는 예측된 후보를 정리합니다. |

### IoU 기준을 바꾸면?

- **낮추면:** 조금만 겹쳐도 제거되므로 중복을 더 강하게 줄입니다. 가까이 있는 서로 다른 물체까지 제거할 수 있습니다.
- **높이면:** 많이 겹쳐야 제거되므로 중복 후보가 더 남을 수 있습니다.

NMS는 bounding box가 겹친다는 단서를 이용할 뿐, 두 후보가 실제로 같은 물체인지를 완벽하게 아는 것은 아닙니다.

함수의 입력 형식과 제거 기준은 [torchvision NMS 공식 문서](https://docs.pytorch.org/vision/stable/generated/torchvision.ops.nms.html)를 참고하세요.
