# Hidden State (은닉 상태)

**Hidden state는 RNN이 지금까지 읽은 입력의 정보를 다음 시점에 전달하기 위해 만드는 숫자 벡터입니다.** 쉽게 말하면, 입력을 하나씩 읽으면서 계속 고쳐 쓰는 ‘기억 메모’입니다.

여기서 벡터는 숫자를 순서대로 모아 놓은 것입니다. `hidden_size=64`라면 한 시점의 기억을 64개의 숫자로 표현합니다.

### 1. 왜 필요한가요?

KOSPI의 최근 20거래일을 보고 다음 거래일 종가를 예측한다고 생각해 봅시다. 하루씩 따로 보면 이전 날짜에서 이어지는 흐름을 활용하기 어렵습니다. RNN은 오늘의 입력과 어제까지의 hidden state를 함께 사용해 새로운 hidden state를 만듭니다.

```text
1일차 특성 10개 + 초기 기억 h₀ → 1일차 기억 h₁
2일차 특성 10개 + 1일차 기억 h₁ → 2일차 기억 h₂
3일차 특성 10개 + 2일차 기억 h₂ → 3일차 기억 h₃
...
20일차 특성 10개 + 19일차 기억 h₁₉ → 20일차 기억 h₂₀

마지막 층의 h₂₀ → Linear 층 → 다음 거래일 종가 예측
```

`h₂₀`은 20일차 입력뿐 아니라 앞선 날짜들의 영향을 받은 상태입니다. 다만 20일치 원본 데이터를 그대로 저장하거나, 모든 정보를 완벽하게 기억하는 것은 아닙니다.

### 2. 기억은 어떻게 만들어지나요?

기본 RNN의 한 층에서는 다음 계산을 매 시점 반복합니다.

```text
h_t = tanh(W_x × x_t + W_h × h_(t-1) + b)
```

| 기호 | 의미 |
| --- | --- |
| `x_t` | 현재 시점의 입력. 실습에서는 하루의 특성 10개 |
| `h_(t-1)` | 이전 시점까지의 정보를 담은 hidden state |
| `h_t` | 현재 입력까지 반영한 새로운 hidden state |
| `W_x`, `W_h` | 입력과 이전 기억을 어떻게 조합할지 학습하는 가중치 |
| `b` | 학습하는 편향. 위 식은 편향들을 하나로 합친 표현 |
| `tanh` | 계산 결과를 -1과 1 사이로 바꾸는 활성화 함수 |

학습 과정에서는 예측 오차를 줄이는 방향으로 가중치와 편향이 바뀝니다. 그 결과, 어떤 정보를 hidden state에 반영할지도 학습됩니다. hidden state 자체는 입력을 처리할 때마다 계산되는 값이며, 가중치처럼 고정된 모델 파라미터는 아닙니다.

‘64개 숫자 중 첫 번째는 상승 추세, 두 번째는 변동성’처럼 사람이 의미를 지정하지 않습니다. 정보가 여러 숫자에 나뉘어 표현될 수 있으므로 각 숫자에 명확한 이름을 붙이기는 어렵습니다.

### 3. 실습의 설정값과 구분하기

| 설정 | 실습 값 | 뜻 |
| --- | --- | --- |
| `input_size` | 10 | 하루에 입력하는 특성 개수 |
| `sequence_length` | 20 | 한 샘플에서 차례로 읽는 거래일 수 |
| `hidden_size` | 64 | 각 층이 각 시점의 기억을 표현하는 숫자 개수 |
| `num_layers` | 2 | 위아래로 쌓은 RNN 층 개수 |
| `batch_size` | 최대 64 | 한 번에 처리하는 샘플 개수 |

**20은 읽는 날짜 수이고, 64는 기억 벡터의 크기입니다.** `hidden_size=64`는 64일을 기억한다는 뜻이 아닙니다. 또한 배치 크기와 hidden 크기가 모두 64인 것은 우연이며, 서로 다른 설정입니다.

실습은 RNN이 2층입니다. 첫 번째 층은 하루 특성 10개와 자기 층의 이전 기억을 사용합니다. 두 번째 층은 같은 시점의 첫 번째 층 출력과 자기 층의 이전 기억을 사용합니다. 각 층에는 별도의 hidden state가 있습니다.

### 4. 코드의 `out`과 `h_n` 읽기

실습의 단방향 RNN에서 `batch_first=True`, `num_layers=2`, `hidden_size=64`이고 배치에 샘플이 4개 있다면 다음과 같습니다.

```python
# x.shape: [4, 20, 10]
out, h_n = model.rnn(x)

# out.shape: [4, 20, 64]
# 마지막 RNN 층의 모든 시점 hidden state

# h_n.shape: [2, 4, 64]
# 각 RNN 층의 마지막 시점 hidden state

last_hidden = out[:, -1, :]  # [4, 64]
# 모든 샘플에서 마지막 시점의 기억 64개를 선택
# 이 실습의 단방향 RNN에서는 h_n[-1]과 같은 값

pred = model.fc(last_hidden)  # [4, 1]
# 샘플마다 다음 거래일 종가 예측값 한 개
```

`out[:, -1, :]`의 첫 번째 `:`는 모든 샘플, `-1`은 마지막 시점, 마지막 `:`는 hidden 벡터의 모든 숫자를 뜻합니다.

`out`과 `h_n`은 같은 기억을 서로 다른 범위로 제공합니다. `out`은 **마지막 층의 모든 시점**, `h_n`은 **모든 층의 마지막 시점**입니다. `batch_first=True`여도 `h_n`의 축 순서는 `[층, 배치, hidden 크기]`입니다. 위 모양과 동등 관계는 실습의 단방향 설정 기준입니다.

실습에서 `Linear`가 내놓는 값은 스케일링된 종가 예측입니다. 실제 종가 단위로 읽으려면 학습 때 사용한 `scaler_y`로 역변환해야 합니다.

### 5. 초기 기억과 샘플 간 기억

실습은 `model.rnn(x)`에 초기 상태를 따로 전달하지 않으므로, 호출할 때 초기 hidden state는 0으로 시작합니다. 배치 안의 각 샘플도 각자의 기억을 가집니다.

```text
샘플 A: A의 20일 입력 → A의 기억을 순서대로 갱신 → A의 예측
샘플 B: B의 20일 입력 → B의 기억을 순서대로 갱신 → B의 예측
```

샘플 A의 마지막 기억이 자동으로 샘플 B에 전달되지는 않습니다. 이전 호출의 기억을 이어서 쓰려면 코드에서 명시적으로 전달해야 합니다. 실습에서는 각 20일 구간을 독립적으로 처리하기 때문에 학습 샘플의 순서를 섞어도 각 구간 내부의 날짜 순서는 유지됩니다.

### 6. 자주 헷갈리는 점

- **Hidden state가 예측값인가요?** 예측에 사용하는 중간 표현입니다. 실습에서는 64개 숫자를 `Linear(64, 1)`에 넣어 예측값 한 개를 만듭니다.
- **Hidden은 무슨 뜻인가요?** 정답처럼 데이터에 직접 주어지는 값이 아니라, 모델 내부에서 계산되는 상태라는 뜻입니다. 코드로 꺼내 확인할 수 있습니다.
- **오래된 정보를 모두 기억하나요?** 기본 RNN은 반복 계산 중 정보가 희미해질 수 있고, 학습할 때 기울기 소실 등으로 먼 과거의 관계를 배우기 어려울 수 있습니다.
- **LSTM도 같은가요?** LSTM에도 hidden state가 있지만 별도의 cell state가 추가됩니다. 이 문서의 기본 RNN 구조와 구분해서 이해하면 됩니다.

> 기억할 문장: RNN은 ‘현재 입력 + 이전 기억’으로 새 기억을 만들고, 이 실습은 마지막 기억으로 다음 거래일 종가를 예측합니다.
