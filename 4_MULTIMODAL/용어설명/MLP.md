# MLP (Multi-Layer Perceptron, 다층 퍼셉트론)

[용어 목록으로 돌아가기](../용어설명.md)

## 1. 정의

MLP는 여러 완전연결층과 비선형 활성화 함수를 연결한 신경망입니다. 순환 연결 없이 입력에서 출력으로 정보를 처리하므로 [FFN](FFN.md)의 한 종류입니다.

```text
입력 → Linear → 활성화 함수 → Linear → 출력
```

은닉층을 더 쌓을 수도 있습니다. PyTorch의 Linear는 가중치와 편향으로 값을 변환하는 층이며, ReLU나 GELU 같은 활성화 함수가 비선형성을 더합니다.

## 2. 왜 필요한가요?

복잡한 입력 특징과 출력의 관계를 학습하기 위해 사용합니다. 중간에 비선형 활성화 함수 없이 Linear만 여러 번 연결하면 하나의 아핀 변환으로 합칠 수 있으므로, 층을 쌓는 표현력의 이점을 충분히 얻지 못합니다.

## 3. 구체적인 예시

일반적인 분류에서는 입력 특징을 MLP로 가공해 클래스별 점수를 만들 수 있습니다.

```text
입력 특징 4개 → 은닉 특징 16개 → 클래스 점수 3개
```

[ViT](ViT.md) 내부에서는 패치 벡터를 다음과 같이 가공하는 MLP를 사용할 수 있습니다.

```text
768차원 → Linear → 3072차원 → GELU → Linear → 768차원
```

이 MLP는 각 패치 토큰과 [CLS] 토큰에 같은 가중치로 독립적으로 적용됩니다. 이미지 전체를 하나의 벡터로 펼쳐 처리하는 MLP와는 적용 단위가 다릅니다. 블록 안의 MLP와 마지막 분류 헤드도 별도 구성 요소입니다.

## 4. 코드와 주석

```python
import torch
import torch.nn as nn

mlp = nn.Sequential(
    nn.Linear(768, 3072),  # 특징 차원 확장
    nn.GELU(),            # 비선형 가공
    nn.Linear(3072, 768)   # 원래 특징 차원으로 복원
)

x = torch.randn(2, 197, 768)  # 이미지 2장, [CLS]+패치 197개
y = mlp(x)                  # (2, 197, 768)
```

이 코드는 구성과 shape를 보여주는 예시이며 완성된 ViT는 아닙니다. 실제 구현에서는 Dropout 등을 추가하기도 합니다.

## 5. FFN과 MLP의 관계

```text
FFN: 순환 연결 없이 정보를 처리하는 신경망의 넓은 개념
 └─ MLP: 여러 완전연결층과 활성화 함수로 구성한 형태
```

Transformer와 ViT의 FFN은 보통 MLP로 구현하므로 두 용어가 같은 부분의 이름으로 쓰입니다. 다만 모든 FFN이 MLP라는 뜻은 아닙니다.

## 6. 혼동하기 쉬운 개념

- Attention: 토큰끼리 정보를 교환합니다. 블록 안 MLP는 각 토큰 내부 특징을 가공합니다.
- 분류기: MLP를 분류기로 사용할 수 있지만 모든 MLP가 최종 분류기는 아닙니다.
- Linear 한 층: MLP의 구성 요소이며 그 자체로 여러 층으로 된 MLP와 같지는 않습니다.
