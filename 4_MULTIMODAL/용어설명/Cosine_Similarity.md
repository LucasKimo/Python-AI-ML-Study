# Cosine 유사도 (코사인 유사도)

[용어 목록으로 돌아가기](../용어설명.md)

## 정의

Cosine 유사도는 **두 벡터가 얼마나 비슷한 방향을 향하는지** 나타내는 값입니다. 두 벡터를 화살표로 생각하면, 길이가 달라도 같은 방향이면 유사도가 1입니다.

0이 아닌 두 벡터 a, b에 대해 다음과 같이 계산합니다.

```text
Cosine 유사도 = (a · b) / (a의 L2 길이 × b의 L2 길이)
내적 a · b = 같은 위치의 숫자끼리 곱한 값들의 합
```

| 값 | 기하학적 의미 |
| --- | --- |
| 1 | 같은 방향 |
| 0 | 서로 수직 |
| -1 | 정반대 방향 |

## 필요한 이유

벡터 크기보다 방향을 기준으로 임베딩을 비교할 때 사용합니다. CLIP은 대응하는 이미지와 문장이 비슷한 방향을 갖도록 학습되므로, 이미지와 후보 문장의 유사도를 비교해 [Zero-shot 분류](./Zero_shot.md)를 할 수 있습니다.

의미적 해석은 모델과 데이터에 따라 달라집니다. 0이 반드시 '관련 없음', 음수가 반드시 '반대 의미'를 뜻하지는 않습니다. Cosine 유사도는 확률이나 정확도도 아닙니다.

## 구체적인 예시

```text
a = [3, 4], b = [6, 8]
내적 = 3×6 + 4×8 = 50
두 벡터의 길이 = 5, 10
Cosine 유사도 = 50 / (5×10) = 1
```

길이는 달라도 방향이 같으므로 결과가 1입니다. `[1, 0]`과 `[0, 1]`은 수직이므로 0, `[1, 0]`과 `[-1, 0]`은 정반대이므로 -1입니다.

## L2 정규화와의 관계 및 코드

각 벡터를 [L2 정규화](./L2_Normalization.md)하면 길이가 1이 됩니다. 따라서 공식의 분모가 1이 되어 **내적이 곧 Cosine 유사도**가 됩니다.

```python
import torch.nn.functional as F

# 함께 학습된 CLIP 인코더에서 얻은 임베딩이 준비되어 있다고 가정
# image_features: (B, D), text_features: (C, D)
# B: 이미지 수, C: 후보 문장 수, D: 공통 임베딩 차원
image_features = F.normalize(image_features, p=2, dim=-1)
text_features = F.normalize(text_features, p=2, dim=-1)

# .T로 텍스트 행렬을 (D, C)로 전치
# 행렬 곱으로 모든 이미지와 모든 후보의 내적 계산
similarities = image_features @ text_features.T  # (B, C)

# 이미지마다 유사도가 가장 높은 후보 번호 선택
predictions = similarities.argmax(dim=1)  # (B,)
```

이미지 임베딩과 텍스트 임베딩은 단순히 차원만 같으면 되는 것이 아니라, 서로 비교할 수 있도록 학습된 표현이어야 합니다. 0벡터와의 Cosine 유사도는 수학적으로 정의되지 않으며, 구현에서는 eps 등으로 수치 문제를 방지합니다.

## 혼동하기 쉬운 개념과의 차이

| 개념 | 차이 |
| --- | --- |
| 내적 | 벡터 길이의 영향도 받습니다. 두 벡터의 길이가 1일 때 Cosine 유사도와 같습니다. |
| L2 정규화 | 각 벡터의 길이를 맞추는 전처리 연산입니다. Cosine 유사도는 두 벡터를 비교하는 값입니다. |
| 유클리드 거리 | 두 점 사이 거리를 측정하며 작을수록 가깝습니다. Cosine 유사도는 클수록 방향이 비슷합니다. |
| Softmax 확률 | 후보 점수로부터 만드는 상대적인 분포입니다. 순수 Cosine 값 자체는 확률이 아닙니다. |

## CLIP의 logit_scale

일반적인 CLIP은 Cosine 유사도에 학습된 양수 배율 `exp(logit_scale)`을 곱해 logit을 계산합니다. 이 배율은 temperature의 역수에 해당합니다.

```text
Cosine 점수:   고양이 0.8, 자동차 0.2
10배 한 점수: 고양이 8.0, 자동차 2.0
```

동일한 양수를 곱하므로 후보 순위는 같지만, Softmax 적용 후 분포의 뚜렷함은 달라집니다. 가장 높은 후보만 선택한다면 순수 Cosine 유사도로도 같은 순위를 얻습니다.
