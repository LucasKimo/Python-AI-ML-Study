# Zero-shot (제로샷)

[용어 목록으로 돌아가기](../용어설명.md)

## 정의

Zero-shot은 새로운 작업을 수행할 때 그 작업의 정답 예제를 제공하지 않고, 모델이 사전학습으로 배운 능력을 활용하는 방식입니다. Shot은 이 맥락에서 제공하는 예제 수를 뜻합니다.

Zero-shot은 모델이 전혀 학습되지 않았다는 뜻이 아닙니다. 이미 대규모 데이터로 학습된 모델을 사용할 수 있습니다. 또한 후보 클래스의 개수가 0개라는 뜻도 아닙니다.

## 왜 필요한가?

새로운 분류 대상이 생길 때마다 정답 데이터를 모으고 분류기를 다시 학습하려면 시간과 비용이 듭니다. Zero-shot 방식은 사전학습된 표현을 활용해 정답 예제가 없는 작업도 시도할 수 있게 합니다. 다만 별도 학습 없이 항상 높은 정확도를 얻는다는 보장은 없습니다.

## CLIP의 Zero-shot 이미지 분류

CLIP은 이미지와 텍스트를 서로 비교할 수 있는 임베딩 공간으로 변환하도록 사전학습된 모델입니다. 이미지 인코더와 텍스트 인코더를 함께 사용합니다.

1. 후보 클래스를 준비합니다: 고양이, 강아지, 자동차.
2. 클래스 이름을 문장으로 만듭니다: `a photo of a cat`, `a photo of a dog`, `a photo of a car`.
3. 텍스트 인코더로 후보 문장별 임베딩을 만듭니다.
4. 이미지 인코더로 입력 이미지의 임베딩을 만듭니다.
5. 이미지와 각 후보 문장의 유사도를 비교해 가장 높은 후보를 선택합니다.

```text
입력 이미지 → 이미지 인코더 → 이미지 임베딩
                                      ↕ 유사도 비교
후보 설명들 → 텍스트 인코더 → 텍스트 임베딩들
```

예를 들어 고양이 이미지에 대한 설명용 유사도가 다음과 같다면 고양이를 선택합니다.

| 후보 | 유사도 예시 |
| --- | --- |
| a photo of a cat | 0.31 |
| a photo of a dog | 0.20 |
| a photo of a car | 0.08 |

이 수치는 설명용이며 정확도나 확률이 아닙니다. 후보 점수에 Softmax를 적용해도 후보 집합 내의 상대적인 값이므로, 실제 정답 확률로 단정하면 안 됩니다.

## 비교 계산 코드

다음은 CLIP 인코더에서 이미지와 텍스트 임베딩을 이미 얻었다고 가정한 핵심 계산입니다. 모델별 전처리와 인코더 호출은 생략합니다.

```python
import torch.nn.functional as F

class_names = ["고양이", "강아지", "자동차"]

# image_features: (B, D) — 이미지 B장의 임베딩
# text_features: (3, D) — 후보 설명 3개의 임베딩
# 두 임베딩은 함께 학습된 CLIP 인코더에서 얻어야 함
image_features = F.normalize(image_features, dim=-1)
text_features = F.normalize(text_features, dim=-1)

# 길이를 1로 정규화했으므로 내적이 코사인 유사도가 됨
similarities = image_features @ text_features.T  # (B, 3)
pred_indices = similarities.argmax(dim=1)       # 이미지별 최고 후보
pred_names = [class_names[i] for i in pred_indices.tolist()]
```

서로 무관하게 학습된 이미지 모델과 텍스트 모델의 벡터를 단순히 비교하는 것은 이 방식과 다릅니다. 차원만 같다고 의미가 대응하지는 않습니다.

## 혼동하기 쉬운 개념과의 차이

| 개념 | 차이 |
| --- | --- |
| 사전학습 | 기존 데이터로 모델 능력을 학습하는 단계입니다. Zero-shot은 그 능력을 새로운 작업에 사용하는 방식입니다. |
| Fine-tuning | 새 작업 데이터로 가중치를 추가 학습합니다. 위 CLIP Zero-shot 분류는 가중치를 갱신하지 않습니다. |
| Few-shot | 새 작업의 예제를 소수 제공합니다. 분야와 방법에 따라 프롬프트 예시 또는 추가 학습 데이터로 활용합니다. |
| 일반 분류 head | 학습된 고정 출력 클래스에 점수를 냅니다. CLIP Zero-shot은 후보 문장의 임베딩을 만들어 비교합니다. |

## 주의할 점

- 후보에 정답 클래스가 없어도 가장 유사한 후보를 고를 수 있습니다. 자동으로 '모름'을 판단하는 것은 아닙니다.
- 문장의 표현이나 후보 구성에 따라 결과가 달라질 수 있습니다.
- 새 작업 예제를 주지 않았다는 것이 사전학습 데이터에 관련 개념이나 이미지가 전혀 없었다는 뜻은 아닙니다.
- 이 문서의 모델 이름은 **CLIP**입니다. `CPIP`는 오타입니다.
