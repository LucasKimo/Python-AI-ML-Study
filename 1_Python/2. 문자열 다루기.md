# 1. 문자열 함수와 연산자
### 1. 문자열 길이 확인
```
text = "Hello, Python"
print(len(text))
```
### 2. 문자열 합치기
```
name = '김사과'
age = '20살'
message = name + ", " + age
print(message)
```
### 3. 문자열 반복하기
```
apple = "@" * 10
print(apple)
```
#### 4. 문자열 Indexing과 Slicing
- **Indexing**은 순서가 있는 자료형 (list, string, tuple 등)에서 인덱스 값을 이용해 특정 위치의 요소에 접근하는 방법을 의미. data[index] 형태로 원하는 값을 조회 가능. 음수 index 값을 사용해 뒤에서부터 요소에 접근 가능
```
str = 'hello'
print(str[0])
```
- **Slicing**은 순서가 있는 자료형 (list, string, tuple 등)에서 인덱스 범위를 지정하여 원하는 부분만 추출 하는 방법. data[start:end] 형태. start 인덱스부터 end 이전 인덱스까지의 요소를 반환.
```
str = 'hello'
print(str[0:3])
```
# 2. 문자열 메서드
- 문자열을 조작하거나 변환하는 다양한 작업을 수행할 수 있게 하는 함수
### 1. 대소문자 변환
```
text = "Hello, Python!"
print(text.upper())
print(text.lower())
```
### 2. 특정 문자열의 등장 횟수 확인 .count('@')
```
text = "Hello, Python!"
print(text.count('l'))
```
### 3. 특정 부분 문자열의 첫 번째 등장 위치(인덱스) 확인 .find('@')
```
text = "Hello, Python!"
print(text.find('l'))
print(text.rfind('l'))    # 오른쪽부터 l 등장 위치 확인
print(text.find('o', 5))    # 문자열 5번째 인덱스부터 o 등장 위치 확인
```
### 4. 문자열 대체 .replace()
```
text = "Hello, Python"
new_text = text.replace("Python", "World")
print(new_text)    # Hello World
```
### 5. 문자열 양쪽 공백 제거 .strip()
```
text = " Hello "
print(text.strip())
```
### 6. 문자열 분리 .split('')
```
text = 'a b c d'
names = text.split()    
print(names)    # ['김사과', '반하나', '오렌지', '이메론']

text = '김사과,반하나,오렌지,이메론'
names = text.split(',') # ','을 기준으로 분리
print(names)
```
### 7. 문자열 결합 .join
```
city = "서울시"
district = "강남구"
street = "가로수길"
address = ' '.join((city, district, street))

print('주소:', address)  # 주소: 서울시 강남구 가로수길
```
### 8. 접두사와 접미사 확인
```
text = "Hello, Python!"
starts_with_hello = text.startswith("Hello")
ends_with_world = text.endswith("World!")

print(starts_with_hello)  # True 
print(ends_with_world)  # False
```
