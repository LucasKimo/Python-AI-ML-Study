# 4. 자료형
### 1. 기본 자료형 (Primitive Data Types)
1. 숫자형 (Number)
	- 정수형 (int): 소수점 없는 숫자
	- 실수형 (float): 소수점 있는 숫자
2. 문자열형 (str)
	- 글자들의 집합 (문자열) > "hello", '파이썬'
	- 큰따옴표(")나 작은따옴표(') 둘 다 사용 가능
3. 불린형 (bool)
	- 참(True) 또는 거짓(False) 값을 가짐
	- 조건문 등에 많이 사용
### 2. 집합형 자료형 (Collection Types)
1. 리스트 (list)
	- 여러 값을 순서대로 저장 할 수 있는 자료형 [] 사용
	- 값의 중복 허용, 수정 가능
2. 튜플 (tuple)
	- 리스트처럼 여러 값을 저장 하지만 수정 불가능 () 사용
	- 예: (1, 2, 3)
3. 딕셔너리 (dict)
	- 키(key)와 값(value)의 쌍으로 저장 {} 사용
	- 순서 보장, 키는 중복 불가
4. 집합 (set)
	- 중봏 없는 값들의 모음 {} 또는 set() 사용
	- 순서 없음, 인덱싱 불가
# 5. 자료형 변환 (Type Casting)
### 1. 정수형 > 실수형
```
a = 10
b = float(a)
```
### 2. 실수형 > 정수형
``` 
c = 3.14
d = int(c)
```
### 3. 문자형 > 정수형, 실수형
```
e = "100"
f = int(e)
g = float(e)
```
### 4. 정수형/실수형 > 문자형
```
h = 42
i = str(h)

j = 3.14
k = str(j)
```
# 6. 변수 삭제하기
- del 문은 지정된 변수를 제거하고 해당 메모리 공간을 해제
- del 문을 사용하여 변수를 삭제 할 때 해당 변수에 연결된 메모리가 해제되지만, 변수가 참조하던 값 자체는 삭제되지 않는다. 
```
isLover = False
print(isLover)
del isLover
print(isLover)    # 오류남
```
```
name1 = '김사과'
name2 = name1    # name2는 'name1이 아닌 '김사과' 참조

del name1

print(name2)    # 김사과 정상적으로 출력됨 (name1은 삭제 되었지만 참조하던 값인 '김사과'는 그대로 있음.)
```
