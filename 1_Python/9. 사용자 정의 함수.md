
# 1. 사용자 정의 함수

### 1. 함수의 동작
```
def 함수명(매개변수1, 매개변수2, ...):
    # 함수 내용
    return 결과값
```
1. 함수 객체를 메모리에 생성
2. 그 함수 객체에 함수명 이름을 붙임

```run-python
def hello():
    print("안녕하세요")

a = hello
a()
```
### 2. 함수 객체
```
function object
├── 함수 이름
├── 매개변수 정보
├── 실행할 코드 정보
├── 기본값 정보
├── 전역 네임스페이스 정보
└── 클로저 정보
```
```
print(a) # 함수 객체: 함수 자체를 나타내는 객체
print(a.__code__) # 코드 객체: 함수 안에서 실행할 실제 바이트코드 정보를 담고 있는 객체
```
### 3. 함수 호출 시 메모리에서 일어나는 일
```run-python
def add(a, b):
    result = a + b
    return result

x = add(3, 5)
```

1. add 이름이 가리키는 함수 객체를 찾음  
2. 함수 실행을 위한 새 공간 생성  
3. 매개변수 a, b에 값 연결  
4. 함수 본문 실행  
5. return 값 반환  
6. 함수 실행 공간 제거

👉  이때 만들어지는 새 공간을 **스택 프레임(stack frame)** 또는 **함수 호출 프레임**이라고 합니다.

#### 함수 호출 프레임 (call frame)
- 함수가 호출될 때마다 생성되는 독립적인 실행 공간
- stack 형태로 관리되어 함수가 호출될 때 쌓이고 실행 끝나면 제거됨
# 2. 함수 만들기
### 1. 매개변수와 반환 값이 없는 함수

```run-python
def func1():
```

```run-python

func2(10)
func2(4)
```
### 3. 반환 값이 있는 함수
```run-python
def func4():
    return '🎁'

print(func4())

print(f'temp에 저장된 값: {temp}')
```
### 4. 기본값이 설정된 매개변수
기본 매개변수는 함수 생성 시 한번 만들어진다.
```run-python
def func6(num1=0, num2=0):
    sum = num1 + num2
    return sum
    
print(func6())
print(func6(10))
print(func6(10, 3))
# print(func6(, 3))
# print(func6(None, 3))
print(func6(num2=3))
```

### 5. 가변 매개변수
- 함수를 호출할 때 * 를 사용하면 시퀀스 (리스트, 튜플 등)의 요소를 개별적인 위치 인자로 풀어서 전달할 수 있다.
```run-python
def func7(*args):
    return args
    
print(func7())
print(func7(10))
print(func7(10, 30, 50))
```

```run-python
def func8(a, b, c):
    return a + b + c

numbers = [1, 2, 3]
print(func8(*numbers))
```

### 6. 키워드 매개변수
- 일반적으로 기본값이 설정된 매개변수와 함께 사용됨
- 함수의 매개변수에 기본값을 설정하면, 함수를 호출할 때 해당 매개변수를 생략할 수 있음
```run-python
def func9(id, name, age):
    print(f'아이디: {id}')
    print(f'이름: {name}')
    print(f'나이: {age}')
    
func9('apple', '김사과', 20)
func9(age=30, id='orange', name='오렌지')

# 매개변수명과 딕셔너리의 키가 같아야함
# 딕셔너리의 키는 반드시 문자열 형태
dic1 = {'age':25, 'id':'banana', 'name':'반하나'}
func9(**dic1)

# *의 데이터를 보낼 경우 키가 저장
func9(*dic1)
```

# 3. 변수의 범위

- 변수의 범위(scope)는 해당 변수가 프로그램 내에서 참조되고 변경될 수 있는 영역을 의미
### 1. 지역변수 (Local variable)
- 가장 내부의 범위로, 함수 내에서 정의된 변수들이 해당됨.
- 함수 내에서만 접근 가능함
```python
def local_example():
    local_var = "로컬 변수"
    print(local_var)

local_example()
```

### 2. 전역변수 (Global variable)
- 스크립트 전체에서 사용되는 변수
- 함수 외부에 정의된 변수
- 모든 함수에서 접근 가능
- 함수 내부에서 수정하려면 global 키워드 필요
```python
global_var = "I'm a global variable"

def test_global_scope():
    print(global_var)

test_global_scope()
```

``` python
global_var = 10

def modify_global():
    global global_var
    global_var = 20

modify_global()
print(global_var)  # 출력: 20
```

### 3. 클로저 변수  (Closure variable)
- 내부 함수가 외부 함수의 지역 변수를 사용하면, 파이썬은 그 값을 바로 삭제하지 않고 클로저 공간에 보관함
#### 클로저 공간
- 내부 함수가 외부 함수의 변수를 계속 사용할 수 있도록, 그 값을 따로 저장해두는 메모리 영역 (객체 구조)
- _____closure__형태로 보관
- cell 객체로 감싸져 유지지

### 4. 빌트인 함수 (Built-in function)
- print(), len(), type(), range() 등
- 변수 이름을 찾을 때 적용되는 LEGB 규칙 (Local -> Enclosing -> Global -> Built-in)에서 마지막 단계
- 같은 이름의 변수를 직접 정의 하면 Built-in 함수는 가려질 수 있음

# 4. 함수 메모리 제거
- 참조 카운팅과 가비지 컬랙션의 원칙에 따라 동작
- 함수를 참조하는 변수나 요소가 없게 되면 해당 함수는 가비지 컬랙터에 의해 메모리에서 제거될 수 있음
- del 명령어를 사용해 함수에 대한 참조를 명시적으로 제거 가능
- 함수가 즉시 메모리에서 제거된다는 보장은 없음
```python
def func1():
    print('처음으로 만드는 함수')

del func1
# 이후 func1()을 호출하려고 하면 오류가 발생합니다.
```

# 5. 콜백 함수 (Call-back function)
- 다른 함수에 인자로 전달되어, 특정 시점이나 조건이 되었을 때 나중에 호출되는 함수를 의미
- 함수도 객체이기 때문에 변수처럼 전달할 수 있음
- 어떤 작업이 끝난 뒤 실행할 동작을 미리 정의 할 수 있음
- "지금 바로 실행하는 함수"가 아닌 다른 함수에게 맡겨두었다가 필요할 때 호출되도록 하는 함수
```python
def say_hello(name): # Callback 함수
    print(f"{name}님 안녕하세요!")

def execute(callback):
    print("작업을 시작합니다.")
    callback("김사과")
    print("작업을 종료합니다.")

execute(say_hello)
```

# 6. 람다 함수 (Lambda function)
- 이름 없이 간단한 함수를 한 줄로 정의할 수 있는 익명 함수
- 짧고 일회성으로 사용되는 연산을 표현할 때 활용
- def에 비해 구조는 제한적이지만 코드가 간결
- sorted, map, filter 같은 함수에서 콜백 함수로 자주 사용
```python
lambda 매개변수: 반환할_표현식
```

```python
# 일반 함수
def square(x):
    return x * x

print(square(5))

# 람다 함수
square = lambda x: x * x

print(square(5))
```

```python
multiply = lambda a, b: a * b

print(multiply(3, 4))
```

```python
pass_fail = lambda score: "합격" if score >= 60 else "불합격"

print(pass_fail(80))
print(pass_fail(45))
```
#### sorted()
```python
students = [
    {"name": "김사과", "score": 90},
    {"name": "반하나", "score": 75},
    {"name": "오렌지", "score": 100},
]

result = sorted(students, key=lambda student: student["score"], reverse=True)
print(result)
```

#### map()
- 리스트의 각 요소에 같은 작업을 할 때 사용
```python
scores = [70, 80, 90]

result = list(map(lambda score: score + 10, scores))
print(result)
```

#### filter()
- 조건을 만족하는 값만 골라낼 때 사용
```python
scores = [45, 70, 88, 52, 100]

passed = list(filter(lambda score: score >= 60, scores))
print(passed)
```
