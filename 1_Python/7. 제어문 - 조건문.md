- 프로그램의 실행 흐름을 제어하기 위한 문법

# 1. if, elif, else
### 1. if 문
- 가장 기본적인 조건문
- 특정 조건이 참(True)일 경우에만 해당 블록 내의 코드가 실행됨
```
if 조건:
    실행할 코드
```
- 조건은 True 또는 False로 평가될 수 있는 표현식이어야 함.
- 
```
age = int(input('나이를 입력하세요: '))

if age > 19:
    print('성인입니다')
    print('넷플릭스 성인영화를 감상할 수 있습니다')
print('입력한 나이: ', age)
```
### 2. else 문
- 조건문에서 트정 조건이 충족되지 않을 때 실행할 코드 블록을 정의할 때 사용
```
if 조건:
    코드 블록1
else:
    코드 블록2
```

```
text = input("아이디를 입력하세요: ")

# length = len(text) -> 왈라스 사용 안 했을때 변수에 저장 한 후 사용 해야함.

if (length := len(text)) < 3:
    print(f"아이디가 너무 짧습니다. (입력한 글자 수: {length})")
else:
    print(f"아이디 '{text}'는 사용 가능합니다.")
```

### 왈라스 연산자
- := 연산자
- 값을 할당하면서 동시에 그 값을 표현식 안에서 사용할 수 있게 해주는 할당 표현식(assignment expression)
- := 를 사용하면 조건문, 반복문, 컴프리헨션 등에서 값을 한 번 계산하면서 변수에 저장하고 바로 활용할 수 있어 코드가 더 간결해짐
### 3. elif문
주어진 여러 조건 중에서 하나만 참일 때 실행되는 코드 블록
- elif는 if 없이 단독으로 사용 불가
- elif는 필요에 따라 여러 번 사용 가능
- else는 선택적. 사용될 경우, 항상 if나 elif 뒤에 붙음.
```
if 조건1:
    코드 블록1
elif 조건2:
    코드 블록2
elif 조건3:
    코드 블록3
else:
    코드 블록4
```
# 2. if 여러 개 쓰기 vs if ~ elif ~ else 쓰기
### 1. if ~ elif ~ else
```
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("F")
```

👉 조건을 위에서부터 검사하다가  
👉 **처음 True가 나오면 그 이후는 전부 무시**

### 2. if를 여러번
```
score = 85

if score >= 90:
    print("A")
if score >= 80:
    print("B")
if score >= 70:
    print("C")
```

👉 각각 독립적으로 검사됨  
👉 **여러 개가 동시에 실행될 수 있음**

# 3. 조건부 표현식 (Conditional Expression)
조건의 참과 거짓에 따라 값을 선택하는 한 줄짜리 조건문
```
# if~else로 작성
num = int(input('숫자를 입력하세요: '))
if num % 2 == 0:
    print('짝수')
else:
    print('홀수')

# 조건부 표현식으로 작성
num = int(input('숫자를 입력하세요: '))
print('짝수') if num % 2 == 0 else print('홀수')
```
# 4. 구조적 패턴 매칭
```
match 값:
    case 패턴1:
        실행할 코드1
    case 패턴2:
        실행할 코드2
    case _:
        기본 실행 코드 (default)
```

```
month = int(input("월을 입력하세요 (1~12): "))

match month:
    case 1 | 3 | 5 | 7 | 8 | 10 | 12:
        print(f"{month}월은 31일까지 있습니다.")
    case 4 | 6 | 9 | 11:
        print(f"{month}월은 30일까지 있습니다.")
    case 2:
        print("2월은 28일 또는 윤년이면 29일까지 있습니다.")
    case _:
        print("잘못된 월입니다. 1~12 사이의 숫자를 입력해주세요.")
```

```
user = ("김사과", 20)

match user:
    case (name, age) if age > 19:
        print(f"{name}님은 성인입니다.")
    case (name, age) if age > 15:
        print(f"{name}님은 청소년입니다.")
    case (name, age) if age > 6:
        print(f"{name}님은 어린이입니다.")
    case _:
        print(f'{name}님은 유아입니다.')
```

```
# scores = [95, 88, 76]
# scores = (95, 88, 76)
scores = {"국어":95, "영어":88, "수학":76}

match scores:
    case [korean, english, math]:
        print(f"1. 국어: {korean}, 영어: {english}, 수학: {math}")
    case (korean, _, math):
        print(f"2. 국어: {korean}, 수학: {math}")
    case {"국어": korean, "영어": english, "수학": math}:
        print(f"3. 국어: {korean}, 영어: {english}, 수학: {math}")
```

- 리스트와 튜플은 서로 다른 타입이지만, 구조적 패턴 매칭에서는 "시퀀스 패턴"으로 인해 비슷하게 매칭될 수 있음.
- 타입을 분명히 구분하려면 list(), tuple() 패턴을 사용해야함.
```
scores = {"국어":95, "영어":88, "수학":76}
# scores = [95, 88, 76]
# scores = (95, 88, 76)

match scores:
    # 타입 먼저 구분
    case list():
        match scores:
            case [korean, english, math]:
                print(f"리스트 → 국어: {korean}, 영어: {english}, 수학: {math}")

    case tuple():
        match scores:
            case (korean, _, math):
                print(f"튜플 → 국어: {korean}, 수학: {math}")

    case dict():
        match scores:
            case {"국어": korean, "영어": english, "수학": math}:
                print(f"딕셔너리 → 국어: {korean}, 영어: {english}, 수학: {math}")
```
