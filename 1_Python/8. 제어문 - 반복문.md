- 대표적으로 for문과 while문이 있음
- for문: 리스트, 문자열과 같은 iterable 객체의 요소를 순차적으로 반복
- while문: 조건이 True인 동안 계속 실행. break와 continue를 통해 반복 흐름 제어 가능
# 1. while 문

주어진 조건이 참인 동안 반복적으로 코드 실행. 조건이 거짓이 되면 반복 멈춤
``` python
while 조건:
    # 조건이 참인 동안 실행될 코드
```

``` python
i = 1

while i <= 5:
    print('Hello Python')
    i += 1
```

``` python
# 1부터 10까지의 총합
i = 1
sum = 0

while i <= 10:
    sum += i
    i += 1

print(f'1부터 10까지의 합: {sum}')
```

``` python
# 1부터 100까지 짝수의 합
i = 1
sum = 0

while i <= 100:
    if i % 2 == 0:
        sum += i
    i += 1

print(f'1부터 100까지의 짝수의 합: {sum}')
```

``` python
# 원하는 구구단을 입력받아 해당 단의 구구단을 출력
dan = int(input('원하는 단을 입력하세요: '))
print(f'{dan} 단')

i = 1
while i <= 9:
    print(f'{dan} * {i} = {dan * i}')
    i += 1
```

# 2. for 문

- 시퀀스 (리스트, 튜플, 문자열 등)의 각 항목에 대해 반복 작업 수행
- "지정된 범위 내에서 반복"

``` python
# 요소: 반복할 시퀀스의 각 항목이 for 문의 실행 도중에 할당되는 변수
for 요소 in 시퀀스:
    # 요소에 대한 작업 수행
```

``` python
for s in "Hello":
    print(s)
```

``` python
for key, value in dic1.items():
    print(key, value)
```

# 3. range() 함수

- 순차적인 정수의 시퀀스 생성
- 일정한 범위 내에서 반복 작업 수행할 때 유용
``` python
range([start], stop, [step])
```
- start (선택 사항): 기본값은 0
- stop: stop 값 직전까지의 정수를 포함
- step (선택 사항): 값 증가 간격 지정. 기본값은 1
``` python
for i in range(0, 10, 1):
    print(i, end=' ')
    
for i in range(0, 10):
    print(i, end=' ')

for i in range(10):
    print(i, end=' ')
    
for i in range(1, 10, 2):
    print(i, end=' ')
```

``` python
# for 문을 이용하여 1부터 100까지의 짝수의 총합 구하기
sum = 0
for i in range(0, 101, 2):
    sum += i

print(f'1부터 100까지 짝수의 총합: {sum}')
```

# 4. enumerate() 함수

- 반복문을 사용할 때 인덱스와 값을 함께 가져오기 위해 사용되는 내장 함수
- 반복문 내에서 순서를 추적하면서 값과 해당 값의 인덱스를 함께 사용할 때 유용
- (인덱스, 값)의 튜플을 반환하는 iterator 생성
``` python
enumerate(iterable, [start=0])
```

``` python
for e in enumerate('hello', 0):
    print(e)
```

# 7. continue
- 현재 반복을 즉시 건너뛰고 다음 반복으로 넘어가도록 하는 제어문
- continue 아래 있는 코드는 실행하지 않고 반복문의 처음으로 돌아가 다음 조건을 검사하거나 다음 요소 처리
``` python
logs = [
    "INFO: 사용자 로그인 성공",
    "DEBUG: 세션 생성 중",
    "ERROR: 데이터베이스 연결 실패",
    "INFO: 요청 처리 완료",
    "ERROR: 파일 저장 실패",
    "DEBUG: 응답 전송"
]

error_logs = []

for log in logs:
    # 로그가 ERROR로 시작하지 않으면 건너뜀
    if not log.startswith("ERROR"):
        continue
    # ERROR 로그만 리스트에 추가
    error_logs.append(log)

print("오류 로그만 출력:")
for e in error_logs:
    print(e)
```
# 8. break
- 반복문을 즉시 종료시키는 제어문
- break가 실행되면 반복문의 조건관 상관없이 해당 반복문을 완전히 빠져나옴
```
orders = ["마우스", "키보드", "모니터", "그래픽카드", "프린터"]
stock = {"마우스": 10, "키보드": 5, "모니터": 0, "그래픽카드": 2, "프린터": 3}

print("주문 처리 시작")

for item in orders:
    # 재고가 0이면 주문 중단
    if stock[item] == 0:
        print(f"{item} 재고가 없습니다. 주문을 중단합니다.")
        break
    print(f"{item} 주문 완료")

print("주문 프로세스 종료")
```

# 10. 컴프리헨션 (Comprehension)
- 리스트, 세트, 딕셔너리 등의 컬렉션을 간단하게 생성하거나 변형하는 방법 중 하나
- 반복문과 조건문을 사용하여 간결하게 컬렉션을 생성하는 기법
### 1. List Comprehension
```
n = 10

result = [0 for i in range(n)]
print(result)

result = [i for i in range(n)]
print(result)
```

### 2. Set Comprehension
```
li = [1, 2, 3, 4, 5, 2, 3, 4]
unique_numbers = set(li)
print(unique_numbers)

li = [1, 2, 3, 4, 5, 2, 3, 4]
unique_numbers = {x for x in li}
print(unique_numbers)
```

### 3. Dictionary Comprehension
```
names = ['apple', 'banana', 'orange']
name_lengths = {name:len(name) for name in names}
print(name_lengths)
```
