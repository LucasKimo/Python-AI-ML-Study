# 1. 프로그래밍 방법론

- 프로그램을 개발하는 다양한 접근 방식이나 철학
- 프로젝트 규모, 요구 사항, 개발 팀의 특성 등
### 1. 절차적 프로그래밍 (Procedural Programming)
- 절차를 중시하는 방식
- 작업을 순서대로 실행하도록 프로그램을 구성
- 코드가 명령문으로 이루어져있음
- 작업 순서가 중요
- 변수와 함수가 함께 사용됨
- 함수를 통해 프로그램의 기능을 분리 및 코드 중복 줄임
### 2. 객체지향 프로그래밍 (Object-Oriented Programming, OOP)
- 객체 (Object)라는 개념을 사용해 프로그램을 구성
- 객체는 데이터(속성)와 함수(메서드)를 하나의 단위로 묶은것
- 클래스라는 틀을 사용해 객체를 정의, 이를 통해 여러 객체 생성 가능
- 캡슐화 (Encapsulation), 상속 (Inheritance), 다향성 (Polymorphism) 등의 특징을 활용해 코드를 재사용하고 확장 가능
### 3. 함수형 프로그래밍 (Functional Programming)
- 함수를 중심으로 프로그램을 구성
- 수학적인 함수 개념에 기초
- 코드가 간결하고 직관적
- map, filter, reduce 등의 함수나 재귀를 주로 사용하여 데이터 처리 수행

# 2. 클래스 (Class)

- 객체지향 프로그래밍에서 데이터(속성)와 기능(메서드)을 하나로 묶어 객체를 만들기 위한 설계도(템플릿)
- 클래스를 정의하면 그 구조를 기반으로 여러 개의 객체 (인스턴스)를 생성할 수 있음
- 각 객체는 동일한 구조를 가지면서 서로 다른 값을 가질 수 있음
```python
class 클래스이름:
    # 클래스 속성(멤버 변수) 정의
    속성1 = 초기값1
    속성2 = 초기값2

    # 생성자 메서드 (생략 가능)
    def __init__(self, 매개변수1, 매개변수2, ...):
        # 인스턴스 속성 초기화
        self.속성1 = 매개변수1
        self.속성2 = 매개변수2

    # 메서드(멤버 함수) 정의
    def 메서드1(self, 매개변수1, 매개변수2, ...):
        # 메서드 동작 정의
        pass

    def 메서드2(self, 매개변수1, 매개변수2, ...):
        # 메서드 동작 정의
        pass
```

### 객체와 인스턴스

- 객체 (object)와 인스턴스 (instance)는 거의 같은 의미로 사용되지만, 관점에 따라 구분된다.
- **객체**: 메모리에 생성된 모든 실체를 의미하는 **포괄적 개념** (리스트, 함수, 클래스 등 모든 값이 객체)
- **인스턴스**: 특정 클래스에 의해 생성된 객체를 가리키는 **관계 중심의 언어**. "어떤 클래스의 인스턴스"라고 표현
- 모든 인스턴스는 객체이지만, 모든 객체가 특정 클래스의 인스턴스라고 강조해서 부르지 않음
- 인스턴스라는 용어는 주로 클래스와의 관계를 설명할 때 사용

# 4. 생성자 (Constructor)

- 클래스의 인스턴스가 생성될 때 자동으로 호출되는 특별한 메서드
- 객체의 초기화를 담당하며, 객체가 생성될 때 필요한 속성을 초기화하고 설정하는 역할을 함
- 생성자 메서드는  ______init_____ 라고 이름이 정해져 있음. 
- 속성은 self를 사용하여 접근하고 설정
- 이렇게 초기화된 속성은 객체가 생성될 때마다 다른 값을 가질 수 있음
```python
class 클래스이름:
	# 생성자
    def __init__(self, 매개변수1, 매개변수2):
        self.속성1 = 매개변수1
        self.속성2 = 매개변수2
```

```python
class Fruit:
    def __init__(self):
        print(self, 'init 호출!')

apple = Fruit()
```

### 인스턴스 변수

- 각 인스턴스(객체)마다 별도로 생성되는 변수
- 객체를 만들 때마다 self 키워드를 통해 생성자에서 정의되며, 각 객체가 고유한 값을 따로 저장
- 인스턴스 변수는 인스턴스명으로만 접근 가능하며, 다른 인스턴스에 영향을 주지 않고 자신만의 데이터를 가질 수 있어 객체마다 다른 속성값을 저장할 때 사용됨
```python
class Fruit:
    def __init__(self, name, quantity, origin='원산지 미상'):
        self.name = name
        self.quantity = quantity
        self.origin = origin

# Fruit()  # 오류 발생
# TypeError: __init__() missing 2 required positional arguments

apple = Fruit('사과', 10, '한국')
print(apple)
print(apple.name)
print(apple.quantity)
print(apple.origin)

banana = Fruit('바나나', 5, '필리핀')
print(banana)
print(banana.name)
print(banana.quantity)
print(banana.origin)
```

# 5. 메서드 (Method)

- 클래스 내부에 정의된 함수
- 객체(인스턴스)나 클래스와 관련된 동작(행동)을 수행하는 기능
- 메서드의 종류에 따라 
	- **self를** 사용하는 **인스턴스 메서드,** 
	- **cls를** 사용하는 **클래스 메서드(@calssmethod),** 
	- 별도의 참조 없이 독립적으로 동작하는 **정적 메서드(@staticmethod**)로 나뉜다.
- 메서드는 단순한 함수와 달리 특정 객체나 클래스와 연결되어 동작
- 객체의 상태(속성)을 읽거나 변경하는 역할을 함
```python
class Fruit:
    def __init__(self, name, quantity):
        self.name = name
        self.quantity = quantity

    # 인스턴스 메서드
    def print_info(self):
        print(f"과일 이름: {self.name}")
        print(f"수량: {self.quantity}")

    # 인스턴스 메서드
    def add_quantity(self, amount):
        self.quantity += amount
        print(f"{amount}개 추가되었습니다.")


apple = Fruit("사과", 10)
apple.print_info()
apple.add_quantity(5)
apple.print_info()
```

```python
class Order:
    tax_rate = 0.1  # 클래스 변수 (세율: 모든 주문 공통)

    def __init__(self, price, quantity):
        self.price = price        # 상품 가격
        self.quantity = quantity  # 수량

    # 인스턴스 메서드
    def total_price(self):
        return self.price * self.quantity

    # 클래스 메서드
    @classmethod
    def set_tax_rate(cls, rate):
        cls.tax_rate = rate

    # 정적 메서드
    @staticmethod
    def calculate_discount(price, discount_rate):
        return price * (1 - discount_rate)


# 인스턴스 생성
order1 = Order(10000, 2)  # 10000원 상품 2개

# 인스턴스 메서드 호출
print("총 가격:", order1.total_price())  # 20000

# 정적 메서드 사용 (할인 계산)
discounted = Order.calculate_discount(order1.total_price(), 0.2)
print("할인 적용 가격:", discounted)  # 16000

# 클래스 메서드 사용 (세율 변경)
Order.set_tax_rate(0.2)
print("변경된 세율:", Order.tax_rate)  # 0.2
```

### 데코레이터 (Decorator)

- 기존 함수나 메서드를 수정하지 않고, 그 기능을 감싸서(포장해서) 추가 동작을 붙여주는 기능
- 실행 전후에 로그를 출력하거나 권한 체크, 시간 측정 등의 공통 기능을 쉽게 재사용할 수 있게 해줌
- 함수를 인자로 받아 새로운 함수를 반환하는 구조
- @데코레이터이름 형태로 사용하면 해당 함수가 자동으로 데코레이터에 전달되어 기능이 확장됨

### 클래스 변수 (Class Variable)

- 클래스에 속하는 변수
- 클래스가 생성될 때 정의되며 그 클래스로 만들어진 모든 인스턴스(객체)들이 공유하는 변수
- 주로 전체 객체에 공통적인 속성을 저장할 때 사용됨
```python
class Fruit:
    origin = "한국"  # 클래스 변수 (공통 속성)

    def __init__(self, name, quantity):
        # 인스턴스 변수 (각 객체마다 다름)
        self.name = name
        self.quantity = quantity

    def print_info(self):
        print(f'원산지: {Fruit.origin}')   # 클래스 변수
        print(f'이름: {self.name}')       # 인스턴스 변수
        print(f'수량: {self.quantity}')   # 인스턴스 변수


apple = Fruit('사과', 10)
banana = Fruit('바나나', 5)

apple.print_info()
banana.print_info()

print("----- 클래스 변수 변경 -----")
Fruit.origin = '필리핀'

apple.print_info()
banana.print_info()

print("----- 인스턴스 변수로 덮어쓰기 -----")
apple.origin = '미국'  # apple만 따로 가짐

apple.print_info()
print(apple.origin)
print(banana.origin)
```
